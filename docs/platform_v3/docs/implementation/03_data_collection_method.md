# 03 — Phương pháp thu thập dữ liệu

## Hướng hiện tại → ngược lịch sử

1. Chọn garment còn phổ biến hiện nay.
2. Xác định canonical family.
3. Xác định các biến thể đang tồn tại.
4. Tìm cấu trúc hiện tại có nguồn.
5. Truy ngược biến thể lịch sử.
6. Gắn period/region/community bằng assertions.
7. Nối graph bằng relation có evidence.
8. Không ép một “origin” duy nhất nếu tài liệu không hỗ trợ.

## Mỗi garment pilot nên có

- 3–8 nguồn tốt
- 5–20 assertions
- 5–15 attributes
- 3–10 relations
- 3–10 media references
- component structure
- period/region/context qualifiers
- media rights
- generation-critical features

## Cho phép thiếu

Nếu chưa nghiên cứu:
`state = not_collected`

Nếu nghiên cứu mà chưa xác định:
`state = unknown`

Nếu nguồn mâu thuẫn:
`state = disputed`

Không “điền cho đủ”.

## Thứ tự ưu tiên dữ liệu

1. Identity
2. Structure
3. Components
4. Wearing/layering
5. Accessories
6. Materials
7. Period/region/context
8. Variant relations
9. Media
10. Symbolism/interpretation

## Dữ liệu cho AI

Không thu “prompt”.
Thu semantic facts + references.
PromptBuilder sinh prompt sau.
